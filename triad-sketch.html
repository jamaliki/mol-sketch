SVG keeps every line and fill as vector; the paper, grain and watercolour layers are embedded as images at the chosen resolution. Blend modes use mix-blend-mode, which browsers and Inkscape honour; Illustrator flattens them.
The sequence contains one PNG per drawn frame (frames held on twos are not duplicated). Assemble with ffmpeg -framerate 12 -i frame_%04d.png -c:v libx264 -pix_fmt yuv420p out.mp4 when stepping every 2 at 24 fps.
Data
A PDB stack loads one keyframe per file (sorted by filename) or per MODEL in a multi-model file. Bonds come from CONECT records, otherwise from covalent distance. The stack is rotated so its widest spread lies in the picture plane; adjust under View. Each keyframe is shown for the frames set by frames per PDB; bonds that appear or vanish between keyframes are drawn forming or breaking. To add arrows, charges, lone pairs and labels, save the scene JSON after loading and edit it.
